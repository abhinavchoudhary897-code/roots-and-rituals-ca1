# Roots & Rituals

CA1 project K3P26EP–14: Tribal Artisan Cultural Preservation and Fair Trade Exhibition System.

A frontend exhibition built with HTML, CSS and JavaScript. It includes five required art categories, filters, image zoom, room preview, folklore narration and artisan profiles, with fair-trade information.

Open index.html using Live Server. Narration MP3 files are generated with `node scripts/build-narration.cjs` (requires eSpeak and FFmpeg). The browser read-aloud option is a fallback. Source images need internet access. The exhibition links to official GI registration records for all five traditions, documented masterworks and artisan honours. GI registration concerns a craft tradition, not an individual object. Contextual photographs have separately identified file licences; underlying artwork rights and individual object certification are not established for every reference. AI assistance was used in research and code development.
