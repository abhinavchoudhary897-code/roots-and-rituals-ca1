# Roots & Rituals

CA1 project K3P26EP–14: Tribal Artisan Cultural Preservation and Fair Trade Exhibition System.

A frontend exhibition built with HTML, CSS and JavaScript. It includes five required art categories, filters, image zoom, room preview, folklore narration and artisan profiles, with fair-trade information.

Open index.html using Live Server. Narration MP3 files are generated with `node scripts/build-narration.cjs` (requires eSpeak and FFmpeg). The browser read-aloud option is a fallback. Source images need internet access. Institutional references and image credits are displayed on the website; individual artwork certification and reproduction permissions are not established for every reference. AI assistance was used in research and code development.
